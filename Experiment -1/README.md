# Advanced Java Lab Repository

This repository contains Java lab projects for advanced Java coursework, including a Student Registration GUI using Swing.

## Contents
* `StudentRegistration.java` — Java Swing application for registering student details with form validation and confirmation dialog.

## Features
* **Student Registration:** Form fields, validation checks, reset button, and formatted submission confirmation.

## Requirements
* Java Development Kit (JDK 8 or higher)
* A Java IDE or command-line environment for compiling and running Java files.

## How to Run

### Run the Student Registration App
1. Open a terminal in the repository root.
2. Compile:
   ```bash
   javac StudentRegistration.java
   ```
3. Run:
   ```bash
   java StudentRegistration
   ```
